# Handwritten Character Recognition — Task 3 (CodeAlpha Internship)

## Objective
Identify handwritten **digits (0-9)** using **image processing** and a **Convolutional Neural Network (CNN)** built with PyTorch.

## Key Features
- **Dataset:** MNIST — 60,000 training images + 10,000 test images (28×28 grayscale)
- **Model:** 3-layer PyTorch CNN (Conv2d → MaxPool → Dropout → FC) achieving **~98.5% test accuracy**
- **Web Dashboard:** Interactive Flask-based drawing canvas with real-time CNN predictions and a test set evaluator

## Project Structure

```
├── model_def.py          # CNN architecture (ConvNet) + preprocessing utilities
├── train_cnn.py          # Training script (supports subset/epoch/batch-size args)
├── patch_and_train.py    # Fine-tuning script for correcting misclassifications
├── web_app.py            # Flask web dashboard (draw + predict + evaluate)
├── requirements.txt      # Python dependencies
├── data/                 # MNIST dataset (.npy files — not committed, download separately)
│   ├── train_images.npy
│   ├── train_labels.npy
│   ├── test_images.npy
│   └── test_labels.npy
└── models/               # Trained model checkpoint (.pth — generated by training)
    └── cnn_model.pth
```

## Setup & Usage

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Prepare the Dataset

Place the MNIST `.npy` files inside the `data/` directory:
- `train_images.npy` (60,000 × 28 × 28)
- `train_labels.npy` (60,000)
- `test_images.npy` (10,000 × 28 × 28)
- `test_labels.npy` (10,000)

### 3. Train the CNN Model

```bash
python train_cnn.py --epochs 5 --batch-size 64 --subset 20000
```

The trained model will be saved to `models/cnn_model.pth`.

### 4. Run the Web Dashboard

```bash
python web_app.py
# Open http://localhost:5001 in your browser
```

**Features:**
- 🖊️ **Drawing Canvas** — Draw any digit and get real-time CNN predictions
- 📊 **Probability Bars** — View confidence scores for all 10 classes
- 🧪 **Test Set Evaluator** — Browse random test samples with true vs. predicted labels

## CNN Architecture

| Layer | Type | Output Shape |
|-------|------|-------------|
| Conv1 | Conv2d(1→32, 3×3) + ReLU | 32 × 28 × 28 |
| Conv2 | Conv2d(32→64, 3×3) + ReLU | 64 × 28 × 28 |
| Pool1 | MaxPool2d(2×2) + Dropout(0.25) | 64 × 14 × 14 |
| Conv3 | Conv2d(64→128, 3×3) + ReLU | 128 × 14 × 14 |
| Pool2 | MaxPool2d(2×2) + Dropout(0.25) | 128 × 7 × 7 |
| FC1 | Linear(6272→128) + ReLU + Dropout(0.5) | 128 |
| FC2 | Linear(128→10) | 10 |

## Results

- **Test Accuracy:** ~98.48%
- **Validation Accuracy:** ~98.90%
- **Training Loss (final epoch):** ~0.11
